# Shuttle Orbiter Recoloring Kit
TexturesUnlimited Shuttle Orbiter Recolour patch for Benjee10's Shuttle Orbiter Construction Kit
<img width="2069" height="1093" alt="Screenshot 2026-10-10 154154" src="https://github.com/user-attachments/assets/b7febd5c-0157-4919-92f7-25048b69fc08" />

## Install
Requires TexturesUnlimited and SOCK (duh). Merge the GameData folder so files land at GameData/SORK/. (SOCK Recolored is not required.)

## Schemes
<img width="300" height="30" alt="image" src="https://github.com/user-attachments/assets/fd992044-2eb7-4b66-b426-a7dc78194c94" />

Each affected part now has a **Recolor** switch row in the editor with multiple options (depending on each part):
- Stock
- White recolour
- Moonraker recolour
- Columbia Chines
<img width="4096" height="2796" alt="front_TU test_1" src="https://github.com/user-attachments/assets/000939c2-caa0-4cd2-8048-fb5236532b5d" />
