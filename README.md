# Shuttle Orbiter Recoloring Kit
TexturesUnlimited Shuttle Orbiter Recolour patch for Benjee10's Shuttle Orbiter Construction Kit
<img width="1593" height="992" alt="image" src="https://github.com/user-attachments/assets/fdbe8d32-c4b8-44db-9feb-20c9a4d814c9" />

## Install
Requires TexturesUnlimited and SOCK (duh). Merge the GameData folder so files land at GameData/SORK/. (SOCK Recolored is not required.)

## Schemes
Each affected part now has a **Recolor** switch row in the editor with multiple options (depending on each part):
- Stock
- White recolour
- Moonraker recolour
- Columbia Chines

Each option can be used at the same time.
